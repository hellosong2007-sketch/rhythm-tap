# App for building · เกมตบจังหวะ

โฟลเดอร์นี้รวมไฟล์ของเกม **เกมตบจังหวะ** (Rhythm Tap) วิชา 3500230 ไว้ที่เดียว

## ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเกม เปิดเล่นได้ทันทีด้วยการดับเบิลคลิก |
| `01-rhythm-tap-spec.md` | สเปกฉบับเต็มที่ใช้สั่งสร้างเกม (ต้นทางของทุกอย่าง) |
| `README.md` | คำอธิบายนี้ |

ตัวเกมเป็นไฟล์เดียวจบ ไม่มีไฟล์ประกอบ ไม่มี build step ไม่โหลดอะไรจากอินเทอร์เน็ต และไม่เรียก AI ตอนใช้งาน

## เปิดเล่น

ดับเบิลคลิก `index.html` แล้วกด **เริ่มเล่น** หนึ่งครั้งก่อน เพื่อให้เบราว์เซอร์ปลดล็อกเสียง

## ปล่อยขึ้นเว็บ

อัปโหลด `index.html` ไฟล์เดียวขึ้น GitHub Pages, Netlify Drop หรือ Vercel แล้วเปิดลิงก์บนมือถือ ทดสอบหนึ่งรอบก่อนแจก

## สั่งสร้างใหม่หรือแก้ไข

วาง `01-rhythm-tap-spec.md` ทั้งไฟล์ในแชทใหม่ พร้อมข้อความนี้

> Build the web app described in the spec below. Follow it exactly: it is a complete spec, including the exact Thai UI strings, the design tokens and the acceptance tests. Return only what the "Output format" section asks for.

ถ้าให้ AI แก้ ให้แก้ทีละเรื่อง และขอไฟล์เต็มกลับมาเสมอ อย่ารับคำตอบแบบ "ส่วนที่เหลือเหมือนเดิม"

## สถานะของไฟล์นี้

`index.html` ในโฟลเดอร์นี้เป็น build ที่แก้ล่าสุดเมื่อ 8 พ.ย. 2569 เวลา 22:02 ตรงกับไฟล์ต้นฉบับใน `deploy-projects/rhythm-tap/`

ตรวจแล้ว:

- เปิดจาก `file://` และเล่นจบหนึ่งรอบที่ 100 BPM ได้
- ที่ 320 และ 390 px ไม่มีแถบเลื่อนแนวนอน และปุ่มตบยังมีขนาด 176 × 176 px
- ไม่มี console error และไม่มี request ออกนอกไฟล์

ยังไม่ได้ตรวจ acceptance test ครบทุกข้อกับ build นี้ และยังไม่ได้ฟังเสียงด้วยหู ต้องลองหูฟังที่เครื่องแล็ปก่อนใช้จริง

## ต้นฉบับ

สำเนาต้นฉบับยังอยู่ที่:

- ตัวเกม: `deploy-projects/rhythm-tap/index.html`
- สเปก: `deploy-projects/specs/01-rhythm-tap-spec.md`

ถ้าแก้ในโฟลเดอร์นี้แล้วต้องการให้เว็บจริงเปลี่ยนด้วย อย่าลืมคัดลอก `index.html` กลับไปที่ต้นฉบับ
